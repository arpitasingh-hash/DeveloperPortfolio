## Binary Number Representation

### 1. Decimal to Binary Conversion

Convert 75 into binary using repeated division by 2.

| Division | Quotient | Remainder |
|---|---|---|
| 75 / 2 | 37 | 1 |
| 37 / 2 | 18 | 1 |
| 18 / 2 | 9 | 0 |
| 9 / 2 | 4 | 1 |
| 4 / 2 | 2 | 0 |
| 2 / 2 | 1 | 0 |
| 1 / 2 | 0 | 1 |

Reading remainders from bottom to top:

75 (Decimal) = 1001011 (Binary)

### 2. Binary to Decimal Conversion

Convert 110101 into decimal.

110101₂

= (1 × 2⁵) + (1 × 2⁴) + (0 × 2³)
  + (1 × 2²) + (0 × 2¹) + (1 × 2⁰)

= 32 + 16 + 0 + 4 + 0 + 1

= 53 (Decimal)

### 3. Why Computers Use Binary

Computers use binary because electronic circuits
can easily represent two states, ON (1) and OFF (0),
making data processing reliable and efficient.
